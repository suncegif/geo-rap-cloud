# 91 BPM 节奏契约

## 不可漂移参数

| 参数 | 固定值 |
|---|---|
| 拍速 | 91 BPM，验收容差 90–92 |
| 拍号 | 4/4 |
| 一拍 | 0.65934 秒 |
| 十六分音符 | 0.16484 秒 |
| 30 fps 画面槽位 | 约 4.95 帧，制作时按 5 帧规划 |
| 普通短停顿 | 1 个槽位，约 0.165 秒 |
| 句末停顿 | 2–4 个槽位，约 0.33–0.66 秒 |
| 段落停顿 | 1–2 拍，约 0.66–1.32 秒 |

## Flow

- 一个普通汉字占一个十六分槽位。
- 英文字母缩写按实际读音规划槽位，通常每个字母 1 个槽位；例如两字母缩写占 2 个槽位、三字母缩写占 3 个槽位。
- 中文逗号占 1 个休止槽；句号、问号、叹号占 2 个休止槽。
- 每小节 16 个十六分槽位。
- 关键词优先落在每小节第 1、5、9、13 槽。
- 不为追求满拍而吞字；过密时改写或跨小节，不把整体 BPM 提高。
- 每 1–2 小节安排一次短停顿、重读或鼓组留白。
- 尾字使用短促下压或断音，不拖成长音。

## 编曲

- Boom bap 与 modern trap 混合。
- Kick 强、snare 清晰，hi-hat 紧密但不盖字。
- 使用温暖 sub bass、稀疏暗色 synth stab 和四小节一次的停顿/填充。
- 人声位于混音前方；伴奏为人声留出 1–4 kHz 空间。
- 前奏最长 2 秒，结尾允许 0.5–1 秒尾奏。

## 画面同步

- 30 fps 下每个普通字按 5 帧规划。
- 关键词在强拍同步黄色强调、公式变化、人物动作或镜头推近。
- 大段落每 4–8 小节切换视觉状态。
- 45%–65% 处设置二次钩子。
- 计划时间用于编排；最终字幕必须以生成音频的实际转写/对齐结果为准。
